# 12. Źródła i bibliografia (do weryfikacji formatu)

Pozycje ogólnie znane. Przed użyciem sprawdź pełne dane (rok, wydawca, URL, data dostępu) i dopasuj do wzoru cytowania uczelni.

## Dostępność i użyteczność

- W3C. *Web Content Accessibility Guidelines (WCAG) 2.1*. Kryteria 1.4.3 (kontrast tekstu), 1.4.11 (kontrast elementów nieteksowych), 4.1.2 (nazwa, rola, wartość).
- Nielsen J. *10 Usability Heuristics for User Interface Design*. Nielsen Norman Group.
- Brooke J. (1996). *SUS: a "quick and dirty" usability scale*. W: Jordan P. W. i in. (red.), *Usability Evaluation in Industry*. Taylor & Francis.
- Sauro J., Lewis J. R. *Quantifying the User Experience*. Morgan Kaufmann (interpretacja wyników SUS).
- Material Design. *Accessibility, touch targets (48 dp)*. Google.

## Technologia

- Flutter. *Internationalization (gen-l10n), Accessibility, Testing*. Dokumentacja flutter.dev.
- Dart. *Effective Dart*. dart.dev.
- PrestaShop. *DevDocs: Webservice, module development*. devdocs.prestashop-project.org.
- Firebase. *Google Analytics for Firebase: events, DebugView*. firebase.google.com/docs.
- Google. *Google Sign-In, Places API, Calendar API, Google Pay*. developers.google.com.
- Provider (pakiet Flutter). pub.dev/packages/provider.

## Bezpieczeństwo

- OWASP. *API Security Top 10* (Broken Object Level Authorization, Broken Authentication).
- RFC 6750. *The OAuth 2.0 Authorization Framework: Bearer Token Usage* (schemat `Authorization: Bearer`).
